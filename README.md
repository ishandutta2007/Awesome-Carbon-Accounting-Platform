# Awesome-Carbon-Accounting-Platform

# Top Carbon Accounting Platform Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on GHG Emissions Tracking, Carbon Footprint Calculation & Net-Zero Reporting*  
**Last updated: September 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Carbon Accounting**. These tools measure, track, and report greenhouse gas (GHG) emissions across Scope 1, 2, and 3 categories to support corporate sustainability reporting, regulatory compliance, and net-zero target setting.

**Examples** include Watershed, Persefoni, Sweep, Greenly, Normative, Plan A, Emitwise, Salesforce Net Zero Cloud, IBM Envizi, CarbonChain, Sphera, Sinai Technologies, FigBytes, and SpheraCloud (the category leaders).

**Open-source emphasis**: This section is expanded with active projects for self-hosting, custom emission factor management, and transparent carbon calculations — ideal for organizations, researchers, and developers building vendor-independent carbon accounting solutions. The open-source ecosystem offers a range of options from desktop-first inventory tools to full-stack ESG platforms and specialized calculation engines for specific domains.

Contributions welcome! Open an PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects

- **[CarbonInk](https://github.com/lxzxl/carbonink)**  
  Free, open-source, local-first GHG carbon accounting for the desktop (macOS + Windows). Import utility bills, fuel receipts, and travel documents; AI extracts activity data; produces one-click ISO 14064-1 inventory report — entirely offline with no account, no cloud, no subscription. MIT licensed. Features Scope 1/2/3 inventory, emission factor pinning with audit-grade snapshots, supplier questionnaires, and built-in MCP server for AI agent integration .

- **[GreenOps](https://github.com/cherryaugusta/greenops-carbon-accounting-platform)**  
  Full-stack ESG carbon accounting platform with Django REST Framework backend and React frontend. Tracks employee travel and energy usage, calculates CO₂e using emission factors, and provides manager approval workflows. Features full audit trail via django-simple-history, JWT authentication, Swagger/OpenAPI documentation, dashboard with charts and KPIs, multi-step validated forms, and drag-and-drop report builder. Docker Compose deployment with PostgreSQL and Redis .

- **[OpenGHG Carbon Calculator](https://github.com/mindsongreen/OpenGHG)**  
  Open-source, transparent carbon footprint calculator designed for robust, auditable, and methodology-driven inventories. Key principles: separation of data domains (activity data, emission factors, conversions, parameters), federated database architecture for customer-hosted sensitive data, explicit unit algebra, no black-box calculations, and full traceability. Backend: PHP with PostgreSQL. Frontend: HTML/JavaScript. Supports user-defined mapping and scopes with explicit formulas .

- **[LABeCO2](https://github.com/LABeCO2)**  
  Free and open-source software (GNU GPL v3) calculating the carbon footprint of an experiment, project, or entire laboratory. Covers consumables, machinery and electricity, travel, and waste end-of-life. Runs locally with no account needed and no data transmission. Python-based; available for Windows with macOS/Linux via source. Developed by a postdoctoral researcher at Université Paris-Cité .

- **[C-Module](https://github.com/C-Module)**  
  Open-source Python package for global forest carbon accounting, distributed via PyPI and archived on Zenodo. Traces historical carbon stocks from 1990–2023 using FAO statistics and projects scenarios to 2100 via the TiMBA model. Supports national GHG inventories, NDCs, and carbon market additionality verification. Includes interactive visualization dashboard. Compatible with Python ≥3.9 on Windows, Linux, and macOS .

- **[EPFL CO₂ Calculator](https://github.com/epfl-enac/co2-calculator)**  
  Open-source carbon footprint assessment tool developed at EPFL, compliant with the GHG Protocol. Originally built for internal EPFL use, now intended for broad adoption. Under active development (pre-production v0.x.x, targeting v1.0.0 public release). Licensed under GNU GPL v3.0 .

- **[carbonpredict](https://github.com/david-leake/carbonpredict)**  
  R package (CRAN) predicting Scope 1, 2, and 3 carbon emissions for UK Small and Medium-sized Enterprises (SMEs) using Standard Industrial Classification (SIC) codes and annual turnover data. Also predicts Scope 1 emissions for UK farms. Uses pre-trained models from peer-reviewed research. Provides single and batch prediction, plotting, and workflow tools. MIT licensed .

- **[CO2.js](https://github.com/thegreenwebfoundation/co2.js)**  
  Open-source JavaScript library from The Green Web Foundation for estimating carbon emissions linked to websites, software, and apps. Provides access to net intensity data for different countries and regions. Uses Sustainable Web Design Model (SWDM). Used by Mozilla, Website Carbon, Ecograder, and Matomo. Supports estimation of digital product climate impact .

- **[e-footprint](https://github.com/Boavizta/e-footprint)**  
  Open-source toolkit for exhaustively modeling environmental impact of digital services. Current perimeter: carbon footprint associated with fabrication and usage of servers, storage, network, and end-user devices. Python package with graphical interface (beta). Includes tutorial notebook and modeling examples. Designed for separating modeling, optimization, and API logic .

- **[SCOOP Carbon Accounting Project](https://github.com/SCOOP-Carbon-Accounting)**  
  Open-source carbon accounting using metrology discipline with rigor of financial reporting frameworks. Supports IEEE standards efforts including P7802 and P3469, translating scientific principles into practical projects .

- **[CityCatalyst](https://github.com/Open-Earth-Foundation/CityCatalyst)**  
  Open-source carbon accounting platform for cities, developed by Open Earth Foundation. 35+ stars with active development .

- **[beru](https://github.com/rmrt1n/beru)**  
  Carbon accounting platform using the e-liability approach. Svelte-based, lightweight implementation .

### Additional Strong Open-Source Options

- **WasCAD (Waste Climate Action Data Tool)** — Open-source tool supporting countries to systematically assess climate action impacts in the waste sector. Standard methodologies, calculations, and reporting in one place. Affero GPL with Commons Clause (non-commercial) .
- **zero-carb** — Application measuring software energy consumption and computing software carbon intensity for data-driven decision making. C# based .
- **ignite-analytics/carbon-accounting** — Public repository describing Ignite Procurement's carbon accounting methodology, including Exiobase database changes. Jupyter Notebook .
- **smart-carbon-footprint-tracker** — Web-based personal carbon footprint tracking system with dashboard visualization and recommendations .
- **Eco-Agent** — Client-side carbon footprint calculator from daily habits with Eco-Score and actionable tips. HTML/CSS/JavaScript, no backend required .

**Frameworks for building custom carbon accounting solutions**: For desktop-first, offline-capable corporate GHG inventory with AI-assisted data extraction, **CarbonInk** provides a complete ISO 14064-1 workflow . For full-stack ESG platform development, **GreenOps** offers a production-oriented Django/React reference with audit trails and report building . For transparent, auditable calculations with explicit unit algebra, **OpenGHG** provides the most methodology-forward approach . For SME emission prediction without primary data collection, **carbonpredict** offers a peer-reviewed statistical model . For digital carbon footprint (websites, software), **CO2.js** and **e-footprint** provide specialized tools . For research and policy analysis in forestry, **C-Module** offers country-level projections aligned with international climate commitments . Note that full enterprise carbon accounting with automated data ingestion, regulatory disclosure workflows (CSRD, CDP, TCFD), and supply chain engagement remains primarily commercial territory; open-source stacks provide calculation engines, inventory management, and audit foundations that require integration for complete corporate sustainability reporting.

## Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.
- Carbon accounting tools must comply with applicable standards (GHG Protocol, ISO 14064, CSRD, CDP) and regional regulatory requirements.
- Self-hosted open-source solutions require proper infrastructure, emission factor database maintenance, and ongoing methodology updates. Carbon calculations should be validated against recognized standards before use in regulatory disclosures.
- The open-source ecosystem provides strong calculation engines, inventory tools, and specialized domain calculators, but full enterprise carbon accounting platforms with automated data ingestion, audit workflows, and regulatory reporting remain primarily commercial offerings.
